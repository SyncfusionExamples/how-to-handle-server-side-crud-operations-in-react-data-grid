# How to Handle Server-Side CRUD Operations in React Data Grid
A quick-start project that demonstrates server-side CRUD operations in the Syncfusion React Data Grid. This project includes examples using URL DataManager to perform create, read, update, and delete actions through API endpoints, along with handling CRUD events.

Refer to the following documentation to learn about the React Data Grid component: 
https://ej2.syncfusion.com/react/documentation/grid/connecting-to-adaptors/url-adaptor
 
Check out this online example of the React Data Grid component:
https://ej2.syncfusion.com/react/demos/#/tailwind3/grid/default
 
## Project prerequisites

- Node.js (v16 or later)
- .NET 7 SDK or later
- npm or yarn
- Visual Studio or VS Code
 
## How to run this application
To run this application, you need to first clone the `how-to-handle-server-side-crud-operations-in-react-data-grid` repository and then open it in Visual Studio or VS Code. Navigate to the React project directory and install dependencies using `npm install`. Now, simply Build and run your project using the `dotnet build` and `dotnet run` command to view the output.
